# Mockup prompt set

These are the final built-in ImageGen prompts used for the AuDHDMAP concept mockups. All images depict the same workspace, `Home server rebuild`, so theme and view differences can be compared without changing the product underneath them.

## Shared product requirements

- Desktop web application, 16:10 landscape.
- Realistic, shippable product UI rather than concept art.
- Product name rendered exactly as `AuDHDMAP`.
- Main navigation includes `Canvas`, `Outline`, `Board`, `Timeline`, and `Gantt`.
- The workspace contains the thoughts `Home server rebuild`, `Inventory`, `Storage plan`, `Backups`, `Network`, `App migration`, and `Test restore`.
- A persistent saved-state indicator is visible.
- Typography is readable, controls are practical, and spacing is polished.
- No medical claims, mascots, marketing slogans, external brands, watermarks, or illegible decorative microcopy.
